Google Drive Integration & Setup

Direct OAuth & Step-by-Step Guide

Video Tutorial (Step-by-Step) Open Google Cloud Console

Complete Setup Guide (Hindi + English):

  1. Step 1 (Open Console): console.cloud.google.com par jayein aur ek New Project create karein.
  2. Step 2 (Enable API): APIs & Services -> Library me search karein "Google Drive API" aur use Enable karein.
  3. Step 3 (OAuth Consent Screen): OAuth consent screen me jayein, External select karein, App Name me QR INSTANT aur apna Gmail daal kar Save karein.
  4. Step 4 (Create Credentials): Credentials -> Create Credentials -> OAuth client ID select karein. Application type me "Web application" choose karein.
  5. Step 5 (Authorized JavaScript Origins): "Authorized JavaScript origins" me apni Blogger / GitHub website ka URL add karein (Jaise: https://undercoverking360-svg.github.io).
  6. Step 6 (Copy & Paste): Jo Client ID milega (ending with .apps.googleusercontent.com), use upar wale box me paste karke Save & Connect daba dein!
💡 Zero Setup Direct Method: Agar aapko Cloud Console setup nahi karna, to aap bina login kare bhi apne Google Drive se share link copy karke direct "Or Paste Any Google Drive Link" box me daal sakte hain!
